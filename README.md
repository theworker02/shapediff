# shapediff

Shape identifiers and diff tokens for idempotent workflows.

**Site:** https://theworker02.github.io/shapediff/

## Install / run

```bash
git clone https://github.com/theworker02/shapediff.git
cd shapediff
node src/cli.js
node --test
```
